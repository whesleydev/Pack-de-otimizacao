# Fontes empacotadas — créditos e licença

As fontes abaixo são **empacotadas no app e no site** (nada de CDN: sem internet
a fonte continua funcionando). Todas são de licença livre e podem ser
redistribuídas; os nomes das famílias e os créditos ficam preservados aqui.

| Arquivo | Família | Autor / origem | Licença |
|---|---|---|---|
| `pressstart2p.ttf` | Press Start 2P | CodeMan38 | SIL Open Font License 1.1 |
| `monocraft.ttf` | Monocraft | Idrees Hassan | SIL Open Font License 1.1 |
| `anton.ttf` | Anton | Vernon Adams, Cyreal | SIL Open Font License 1.1 |
| `bebasneue.ttf` | Bebas Neue | Ryoichi Tsunekawa (Dharma Type) | SIL Open Font License 1.1 |
| `orbitron.ttf` | Orbitron | Matt McInerney | SIL Open Font License 1.1 |
| `russoone.ttf` | Russo One | Jovanny Lemonad | SIL Open Font License 1.1 |
| `playfairdisplay.ttf` | Playfair Display | Claus Eggers Sørensen | SIL Open Font License 1.1 |
| `jetbrainsmono.ttf` | JetBrains Mono | JetBrains | SIL Open Font License 1.1 |
| `caveat.ttf` | Caveat | Impallari Type | SIL Open Font License 1.1 |

O texto da SIL Open Font License 1.1 está em <https://scripts.sil.org/OFL> e
acompanha cada arquivo `.ttf` (o nome da licença está gravado dentro da própria
fonte, campo *License*).

Nenhuma dessas fontes é de terceiro "de peso" redistribuído junto do pack: são
fontes livres usadas apenas como opção de aparência do painel, e o usuário pode
voltar para a fonte do sistema a qualquer momento em **Configs → Fonte**.
