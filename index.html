🎛️ Menu-mestre: um comando para tudo

Com Termux (ou Shizuku/root), um único comando abre o menu que gerencia o pack inteiro — aplicar, reverter, performance, jogo, Free Fire, debloat, toque e snapshots:

sh pack.sh          # abre o menu numerado
sh pack.sh status   # o que já está aplicado
sh pack.sh apply    # aplica o recomendado (sem root)
sh pack.sh restore  # desfaz TUDO de uma vez
💡 O run.sh do nível 2 é só um atalho para esse mesmo menu.

🖥️ Painel web (PHP): controle pelo navegador

Prefere clicar em botões? Um comando sobe um painel web completo e te dá uma URL para abrir no PC (mesma rede Wi-Fi). De lá você escolhe o DNS, limpa RAM/cache, troca o renderizador (Skia/Vulkan), seleciona um app/jogo para usar ANGLE/Vulkan, ajusta o touch, o debloat e muito mais — com confirmação nas ações de risco.

sh main.sh              # menu principal (baixar full, subir servidor, abrir painel)
sh main.sh web start    # sobe o painel e mostra a URL com token
sh main.sh web url      # só imprime a URL
sh main.sh baixar       # baixa os recursos FULL do pack
🔒 O acesso é por token e o painel só executa scripts de uma lista branca (valida pacote/host/número). Precisa de PHP (Termux: pkg install php).

Passo a passo

  1. Instale o app do seu caso (veja a seção Apps).
  2. Salve um snapshot antes de mexer: sh pack.sh snapshot save.
  3. Aplique o que quiser: cole um .txt no Brevent, ou rode sh pack.sh (o menu-mestre) no Termux.
  4. Teste no treino (principalmente toque/sensibilidade) antes de partida.
  5. Não gostou? Reverta com o 99-restaurar-tudo.txt ou sh pack.sh restore.
💡 Dica de ouro: use a área de Comandos abaixo para aplicar um ajuste de cada vez e ver o efeito. É mais seguro do que aplicar tudo de uma vez.

🧰 Área de comandos

Comandos soltos para copiar e colar. No Brevent, cole direto no campo de comando. No ADB, use adb shell "...". No Termux com Shizuku, use rish -c "...". Os marcados como root só funcionam com root.

🔌 Plugins (níveis 3 e 4)

Módulos do AxManager/KernelSU/APatch/Magisk. Empacote com sh scripts/build-plugins.sh e instale o .zip em Plugins → instalar. Cada um tem botão de ação e uninstall.sh que reverte.

⚡ Rodar sem instalar: o menu-mestre executa os módulos e plugins que já vêm na pasta — sh pack.sh modules list e sh pack.sh modules run WS7_OFF7. Isso roda o script avulso no shell atual; para rodar no boot, em segundo plano ou com WebUI, instale no gerenciador.

📦 Módulos do autor

Módulos próprios (MIT) em 00 Otimizações/Modulos/. Empacote com sh scripts/build-modules.sh.

❓ Perguntas frequentes

Preciso de root?

Não. Os níveis 1 e 2 e boa parte dos plugins funcionam sem root (Brevent, Shizuku ou AxManager). Root só é necessário para as otimizações profundas (sysfs, GPU, térmico).

Isso danifica o telefone?

Os comandos são ajustes de configuração e são reversíveis. O risco existe em otimizações profundas (root) e no ajuste de toque — por isso há trava térmica e restauração. Salve um snapshot antes.

Como eu reverto tudo?

Nível 1: cole o 99-restaurar-tudo.txt. Nível 2: run.sh restore. Plugins: o uninstall.sh de cada um. Profundas: sh scripts/deep-tune.sh restore.

O que é o "renderizador" (Vulkan/Skia/ANGLE)?

É o motor gráfico que desenha a interface. O Android aceita só dois valores: skiagl e skiavk — qualquer outro é ignorado. O OpenGL foi removido no Android 10, então opengl só vale em aparelho antigo. Sem nada setado, quem escolhe é o sistema (o padrão). ANGLE traduz OpenGL para Vulkan e pode melhorar jogos específicos. Veja a categoria Renderizador nos comandos.

Congelei um app e ele não abre. E agora?

Rode pm unsuspend --user 0 PACOTE e pm enable --user 0 PACOTE, ou use 13-descongelar-apps.txt / o plugin 06-freezer (botão descongelar). Nunca congele apps do sistema — o pack já os protege.

Funciona em qualquer Android?

A maioria exige Android 11+. O tuning por jogo (resolução/FPS) pede Android 12+. Veja docs/COMPATIBILIDADE.md.
