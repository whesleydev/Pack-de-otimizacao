# 00deUdia Otimizações

Otimização Android para alto desempenho (foco Free Fire).

## Funções principais
- **Desempenho**: Liberação de RAM, otimização de CPU/GPU, compactação de memória.
- **Otimização de Apps**: Isenção de modo Doze, proteção contra fechamento em segundo plano (anti-relog), gerenciamento de processos.
- **Rede**: DNS privado (DoT) para otimização de ping e privacidade.
- **Sistema**: Ajustes de taxa de atualização da tela (Hz), gerenciamento de telemetria, limpeza de cache/dexopt.

## Requisitos
- Conexão via Shizuku (recomendado) ou ADB por Wi-Fi/USB para aplicar os ajustes privilegiados.
- Permissão de acesso aos dados de uso do sistema para monitoramento em tempo real.
